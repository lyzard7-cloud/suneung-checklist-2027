PDF는 인쇄 창에서 ‘PDF로 저장’을 선택하세요. 완료 기록은 Firebase 서버에 저장되며 승인된 교사와 동기화됩니다. JSON 복원은 실시간 공유 기록을 변경하지 않습니다.
